E. THE THREE ITEMS NEVER DELIVERED
------------------------------------------------------------------------------
E1. A1/A2 handoff correction: corrected implementation or new mechanism.
    Mechanism, from the code (s1_detection.h:432-520, 700-712):
    - S1 added a 50-300 ms handoff-jitter draw to a packet's delay and then tested that
      inflated value against its own threshold.
    - 94.8 % of zero-attack false positives fell in that band (median firing delay
      246.9 ms). The jitter is larger than the 80 ms A1/A2 inject, so no threshold could
      separate the two.
    - The correction stops S1 from accusing on a packet carrying handoff jitter, using
      handoff_just_occurred(vehicle). The serving RSU takes part in that handoff, so this
      is information available at runtime, not oracle knowledge.
    Our reading: a corrected implementation, not a new mechanism. The paper already
    models handoff latency as legitimate (Mechanism 1, and the coefficients of
    eq:mobility_baseline); the detector was double-counting it in its own evidence. If it
    is adopted, it needs one sentence under eq:rule_s1, not a new equation.
    Measured effect with it on:
    - zero-attack false-positive rate 0.022 % +/- 0.014 % (5 seeds);
    - A1 at 60 %, un-deduplicated: recall 95.55 %, FPR 6.48 %, MCC 0.8395, against
      99.13 % / 23.56 % / 0.6368 without it;
    - A2 recall 97.53 %.
    It is OFF in the reported configuration, so the paper cannot claim it unless it is
    enabled for final experiments (D4). The patch adds nothing about it.

E2. Density sweep, 0/20/40/60 %, on A1's residual FPR.
    Never run. It was listed on 31 Aug (HPC task P3) and never started. It needs new
    simulations, so it cannot be delivered now. We propose it for final experiments,
    together with D4, since the handoff suppression setting changes the residual it would
    measure.

E3. A1/A2 recall decay, time-bucketed.
    A 90 s version was sent on 7 Sep (A1A2_RECALL_DECAY_2026-09-07.md). It covered only
    0-80 s, so it could not show a decay across 300 s. Here it is at 300 s on the final
