Two reporting decisions before these are final:

- **MCC definition.** `avg_MCC` (time-average of per-cycle MCC) is what the CSV
  reports; MCC recomputed from the cumulative `TP/FP/TN/FN` is higher in 41 of 49
  runs, mean +0.0485, never lower. `main.tex:5079` lists MCC beside the per-node
  confusion matrix, which reads as MCC **of that matrix** — the cumulative one.
  If `avg_MCC` is printed next to the matrix the two will not reconcile.
- **A6@100 MCC 0.719 -> 0.426 with enforcement on.** Not a detector regression:
  `TP+FN = 263` in both arms, FP and TN unchanged, `FN` rises 3 -> 17. Nodes
  quarantined early stop emitting signal while ground truth still marks them
  malicious for the full run. This is the latch reset-boundary question the
  supervisor already flagged. Do not "fix" it in code.

## 2. P2 — two ablations

Full switch catalogue is in `--PrintHelp`; the useful ones:

| flag | ablation | isolates |
|---|---|---|
| `--enable_quarantine` | AB7 | trust updates + SC.Quarantine |
| `--enable_lrad_obu` / `--enable_lrad_rsu` | AB1 | OBU vs RSU engine (dual-mode claim) |
| `--disable_crypto` | — | DKG + ML-DSA-87 + STARK hop-proof (overhead figure) |
| `--enable_stark_delay` / `--enable_stark_hop` | AB4 | STARK proofs |
| `--enable_witness_mechanism` | AB6 | witness / BFT |
| `--enable_endorsement_requirement` | AB8 | f+1 FlowMod endorsement |
| `--enable_controller_failover` | AB9 | controller trust / revoke / failover |
| `--enable_key_rotation` | AB11 | ZKP key rotation |

**Recommended: AB7 then AB1.**

- **AB7** quantifies what the entire mitigation layer buys, now that enforcement
  actually works. Highest value and closest to what the supervisor is asking.
- **AB1** isolates the dual-mode architecture, a core design claim.
- `--disable_crypto` is a cheap add-on (2 runs/variant) for a crypto-overhead
  figure — complements rather than replaces the above.

### Do not pick AB3 on the "higher number" rule

Measured means over A1-A8:

| ablation | arm A | arm B | result |
|---|---|---|---|
| **AB2** centralized vs federated | 0.4393 | **0.5141** federated | federation **+0.075** — a genuine win |
| **AB3** 5-feature vs 7-feature | **0.5199** 5-feature | 0.5141 7-feature | 5-feature wins by 0.006 |

AB3's higher arm says the extra features contribute nothing — it argues against
the feature set rather than for it. That is consistent with the `d_div` / `a_tp`
finding (global scalars, within-stratum AUC 0.500). Report AB3 as a diagnostic
corroborating that defect, not as a headline ablation. **Hold AB3 entirely until
the supervisor rules on `d_div`/`a_tp`** — if the dataset is regenerated, every
LSTM figure moves.
